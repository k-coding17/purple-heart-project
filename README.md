# Purple Heart Project

Nonprofit website for the Purple Heart Project — introducing combat-wounded veterans to hand tool woodworking therapy.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Run production build locally |
| `npm run lint` | Run ESLint |

## Deploy

Static site — deploy to [Vercel](https://vercel.com) by connecting this repository.
